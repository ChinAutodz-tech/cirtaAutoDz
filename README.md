# CirtaAUTO — نسخة ثابتة متوافقة مع الاستضافة الثابتة

هذه النسخة تحتفظ بتصميم الموقع الحالي وكتالوج السكوترات والدراجات النارية والألوان والهوية البصرية، مع إزالة الاعتماد على Cloudflare Workers وR2.

## ما تغيّر
- إزالة `worker.js` و`wrangler.toml` من نسخة النشر.
- تحويل طلبات التقسيط والاستفسار عن وصل الدفع إلى رسائل واتساب.
- عدم رفع بطاقات الهوية أو كشوف الحساب أو الوثائق المالية عبر صفحة ثابتة.
- الإبقاء على البحث والتصفية وبطاقات المنتجات والنوافذ المنبثقة وروابط واتساب.
- إضافة `.nojekyll` لدعم النشر المباشر من جذر المستودع.

## النشر كملفات ثابتة
ضع محتويات هذا المجلد في جذر مجلد النشر، ثم فعّل مصدر GitHub Pages من `main / (root)` إذا كان ذلك مناسباً لاستخدامك.

## ملاحظة مهمة حول GitHub Pages
GitHub توضح أن Pages خدمة لاستضافة المواقع الثابتة، لكنها تنص أيضاً على أنها ليست مخصصة أو مسموحاً بها كاستضافة مجانية لموقع هدفه تشغيل نشاط تجاري أو تسهيل معاملات تجارية. راجع سياسة الاستخدام قبل اعتمادها لموقع تجاري عام: https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits

هذه النسخة لا تحتوي على قاعدة بيانات أو لوحة إدارة أو رفع ملفات. إذا احتجت لاحقاً إلى استقبال طلبات وملفات بشكل آمن، فستحتاج خدمة خلفية مستقلة.
